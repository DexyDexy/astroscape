# AstroScape — живая карта неба

Интерактивная 3D‑астролябия в браузере: положения планет на тропическом зодиаке, фазы Луны,
ретроградность, восходы и закаты, аспекты и затмения — для любого места и любого момента времени.

## Открыть онлайн

<https://dexydexy.github.io/astroscape/>

Язык интерфейса выбирается автоматически по настройкам браузера: русский, английский, немецкий,
испанский, французский, итальянский, португальский; для остальных языков — английский. Сменить его можно переключателем в тулбаре или параметром
ссылки: <https://dexydexy.github.io/astroscape/?lang=en>. Даты и числа форматируются средствами Intl
в выбранной локали.

## Запуск локально

Сборка не нужна. Достаточно открыть `index.html` в браузере (Chrome, Edge, Firefox, Safari).
На iPhone нужен iOS 16.4 или новее; на более старых версиях import maps подменяет полифил
`es-module-shims`, но производительность не гарантируется.
Библиотеки (three.js, astronomy‑engine, контуры материков) подгружаются с CDN, поэтому нужен интернет.

Вариант с локальным сервером (если браузер ругается на `file://`):

```bash
python -m http.server 8765
```

и открыть <http://localhost:8765>.

## Что на экране

- **Центр** — Земля с сеткой координат (15° и тонкая 5°), побережьями, границами государств, точками крупных городов
  (подписи появляются при приближении и при выборе места), терминатором день/ночь и маркером наблюдателя.
  Земля повёрнута по реальному звёздному времени, золотая точка — подсолнечная точка (где сейчас полдень).
- **Кольца** — как на астрологической карте: каждая планета стоит на своём кольце под своей эклиптической
  долготой. Стебелёк вверх/вниз — эклиптическая широта (преувеличена ×2). Цветные засечки на внешнем кольце —
  проекции планет на зодиак, линия от Земли к Солнцу показывает знак Солнца.
- **Кольцо зодиака** — 12 знаков по 30°, шкала в градусах, цвет сектора по стихии.
- **Золотое кольцо** — горизонт наблюдателя со сторонами света, меридианом и кругами высот 30° и 60°.
  Всё выше кольца сейчас над горизонтом в выбранной точке; подписи тел под горизонтом приглушены.
- **Линии между планетами** — мажорные аспекты (соединение, секстиль, квадрат, тригон, оппозиция);
  яркость линии — точность аспекта.
- **Солнце** окружено венцом из волнистых остроконечных лучей в духе средневековых изображений:
  плоскость всегда развёрнута к камере, по каждому лучу от основания к острию бежит волна.
- **℞** — планета ретроградна. Красное кольцо вокруг маркера.
- **Звёзды** — около 130 ярких звёзд стоят на реальных местах (J2000), фоновые звёзды случайные.
- **Гелио** — переключение в гелиоцентрический вид: орбиты, расстояния в а.е., лучи с Земли показывают,
  в каком знаке планета видна с Земли (и почему бывает ретроградность).

## Панели

- **Время** — локальное время устройства, UTC, юлианская дата, местное звёздное время.
- **Луна** — фаза, освещённость, возраст, знак, расстояние, восход/заход, ближайшие новолуние и полнолуние,
  четверти на месяц вперёд, перигей/апогей.
- **Солнце и день** — восход, заход, долгота дня, кульминация, гражданские сумерки, равноденствия и солнцестояния.
- **Планеты** — знак и градус, высота/азимут, восход/заход. Щелчок по строке или по планете в 3D — подробности
  (созвездие, скорость, расстояние, блеск, элонгация, экваториальные координаты).
- **Ретроградность** — статус каждой планеты, даты текущего/следующего ретроградного периода, отметка «стоянка».
- **Аспекты** — активные мажорные аспекты с орбисом, сходящиеся/расходящиеся.
- **Затмения** — ближайшие лунное и солнечное (глобально) и ближайшее солнечное, видимое из выбранной точки.

## Управление

| Действие | Как |
|---|---|
| Вращать / зум / панорама | ЛКМ / колесо / ПКМ |
| Пуск / пауза времени | Пробел |
| ±1 час, ±1 день | ← →, Shift+← → |
| Вернуться к «сейчас» | N |
| Гео / гелио | H |
| Вид сверху (как карта) | T |
| Сброс камеры | R |
| Аспекты / свечение / подписи звёзд | A / B / S |
| Место наблюдения | L или кнопка «изменить»; кнопка «Выбрать на карте» приближает глобус, щелчок по нему сразу переносит метку, «Применить» сохраняет, «Отмена» возвращает прежнее место |
| Справка | ? |
| Язык | переключатель в тулбаре или `?lang=xx` в ссылке (ru, en, de, es, fr, it, pt) |

Внизу — панель времени: скорость (от реального времени до месяца в секунду), ввод даты, ползунок
с диапазоном от ±12 часов до ±50 лет.

## Место наблюдения и приватность

При первом запуске приложение спрашивает, откуда смотреть на небо, и предлагает три варианта:

1. **По часовому поясу устройства** — без разрешений и без сети: по названию зоны (например, `Europe/Berlin`)
   подбирается ближайший крупный город. Это значение предлагается по умолчанию.
2. **По GPS** — запрашивается только по явному нажатию; координаты округляются до 0,01° (около километра).
3. **Вручную** — щелчком по глобусу, вводом координат или выбором из списка (159 городов всех
   континентов, отсортированы по алфавиту языка интерфейса).

Место хранится только в `localStorage` этого браузера и никуда не отправляется: у приложения нет сервера
и аналитики. Наружу идут только два запроса: библиотеки с CDN и счётчик просмотров в правом нижнем углу
(внешний сервис [Abacus](https://abacus.jasoncameron.dev), передаётся лишь факт открытия страницы;
с `localhost` счётчик читается, но не увеличивается). Если по часовому поясу город подобрать не удалось,
до выбора используется Гринвич.

## Точность и допущения

- Эфемериды — [astronomy‑engine](https://github.com/cosinekitty/astronomy) (точность порядка угловой минуты
  для планет, ~1° долготы для Плутона за пределами 1700–2200 гг.).
- Зодиак тропический, координаты — истинная эклиптика даты.
- Все времена показываются в часовом поясе устройства (браузера), а восход/заход считаются для местных
  солнечных суток выбранной точки. Для точки в другом полушарии это стоит учитывать.
- Место и настройки видов сохраняются в `localStorage` браузера.

